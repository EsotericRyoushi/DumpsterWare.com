The studio

Small studio. Long memory.

DumpsterWare started in 2021 as an excuse to make games. It grew into a place to build the apps and tools we wanted along the way — but the games are still the point.

We're independent, self-funded, and allergic to filler. Whether it's a narrative game or a conduit calculator, the rule is the same — if it doesn't earn its place, it isn't finished.

— Hunter, DumpsterWare

The house rules

What we keep coming back to.

Not a mission statement. Just the things we actually care about.

01

Fun comes first

We make games because we want to. The apps and tools are side quests — useful, but never the whole personality.

02

Small on purpose

Tiny team, tiny downloads, no corporate gloss. If a feature doesn't earn its place, it gets thrown out.

03

Built to be kept

No trend-chasing, no landfill software. We want you to still want to open it next year.
